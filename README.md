# Симметрия молекул — РГР №1 по общей алгебре

Программа `symmetry_viewer.py` показывает операции симметрии трех молекул:

| Молекула | Формула | Группа | Порядок |
|---|---|---|---|
| Борная кислота | B(OH)₃ | C₃h | 6 |
| Трифенилборан | B(C₆H₅)₃ | D₃ | 6 |
| Тетрафенилметан | C(C₆H₅)₄ | S₄ | 4 |

## Установка

Нужен Python 3.8 или новее (https://www.python.org/downloads/).
В терминале (Windows: «Командная строка», macOS: «Терминал») выполнить:

```
pip install numpy matplotlib
```

(SciPy необязателен: если он установлен, поиск совмещения в режиме «Зеркало» точнее)

## Запуск

Перейти в папку с файлом и выполнить:

```
python symmetry_viewer.py
```

(на macOS/Linux может понадобиться `python3` вместо `python`).

Дополнительные режимы:

```
python symmetry_viewer.py --check        # таблица проверки всех операций в консоли
python symmetry_viewer.py --export fig   # сохранить все рисунки отчета в папку fig
                                         # (в т. ч. раскадровки всех операций strip_*.png;
                                         #  --light — светлая тема для печати)
python symmetry_viewer.py --molecule 2   # сразу открыть тетрафенилметан (0–2)
```

## Управление

* **Молекула** — выбор молекулы (слева сверху)
* **Операция** — выбор операции группы; на сцене сразу появляется её элемент
  симметрии (ось — желтый пунктир, плоскость — голубая, центр инверсии — розовая звездочка)
* **▶ Применить** (или пробел) — плавно выполнить операцию. Для Sₙ сначала
  выполняется поворот, затем пауза, затем отражение в плоскости σh
* **↺ Вернуть** (или клавиша R) — обратная анимация в исходное состояние
* **✓ Проверить все** — проверить все операции группы и «лишние» элементы;
  подробная таблица выводится в консоль
* **⇋ Зеркало** — демонстрация хиральности: отражение в зеркале, перенос
  изображения и попытка совместить его с исходной молекулой поворотом.
  Если в группе есть несобственная операция S (σ, i, Sₙ), поворот вычисляется
  точно: Q = S·σ (ахиральная молекула). Иначе ищется наилучший поворот
  (соответствие атомов + алгоритм Кабша); у BPh₃ даже он оставляет
  отклонение 1,31 Å — молекула хиральна
* **исходная модель** — показать/скрыть пунктирную исходную модель для сравнения
* **номера атомов** — подписи. Белые номера едут вместе с атомами, серые
  остаются на исходных местах, поэтому после операции видна перестановка атомов
* Оси координат x, y, z проходят через центр молекулы и подписаны; под заголовком
  показано, где расположен элемент выбранной операции и формула преобразования
  координат, например (x, y, z) → (x, −y, −z)
* Мышью можно вращать сцену, колесом — приближать

## Как устроена проверка

Каждая операция задается матрицей 3×3 (поворот — формула Родрига,
отражение — M = E − 2nnᵀ, инверсия — −E, Sₙ = σh·Cₙ). Новые координаты = X·Mᵀ.
Затем для каждого атома ищется атом **того же элемента** в той же точке
исходной модели (допуск 10⁻³ Å) в фиксированной системе координат, без
какого-либо дополнительного совмещения. Если такое соответствие найдено для
всех атомов, операция принадлежит группе, а найденное соответствие — это
перестановка одинаковых атомов.
